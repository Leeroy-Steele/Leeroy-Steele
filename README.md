## Public projects

### ⭐ [Steele-IT](https://github.com/Leeroy-Steele/steele-it)

A full stack book publishing app built around reusable content. Topics hold the content, and books hold an ordered, indented list of references to topics, so editing a topic once updates every book that uses it.

- **Stack:** .NET 10 / ASP.NET Core API, React + TypeScript, Vite, TanStack Query, Tailwind CSS
- **Design:** business rules are pure, unit-tested functions; topic edits use `If-Match` versioning so concurrent saves can't overwrite each other (412/428); consistent Problem Details errors
- **Documented:** API spec, status code decisions and trade-offs, and what I'd do next, all in the README
